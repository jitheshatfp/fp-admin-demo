# Fitness Passport — Member Portal Demo

This is a **prototype**, not a production application. It exists to communicate what a Fitness Passport member portal experience could look like — the flows, layout, and interactions — using our Fitness Passport design system.

It's intended as a conversation piece for design and product discussions, not as a reference implementation. All member data, names, and identifiers throughout the app are placeholder/randomized demo content.

## What's in here

A simulated member-facing portal covering the core member journeys: dashboard, membership details, visit history, payments, security & MFA, notifications, and support — styled with the Fitness Passport brand (colors, favicon, PWA icons, Open Graph card).

Built on the [Catalyst](https://catalyst.tailwindui.com/) UI kit as a starting point, with Next.js and Tailwind CSS.

## Running locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
